# Customizing Transcription: Timestamps and Language Options

## The Problem We're Solving

In the previous topic, our transcription worked, but it returned only **plain text**, with no timestamps — which isn't useful for things like video subtitles. Let's fix that now.

## Step 1: Finding the Right Method to Use

Looking at `OpenAiAudioTranscriptionModel`, there are only **two** versions of the `.call(...)` method:

1. `.call(Resource resource)` → the simple version we already used (just the audio file, no extra options)
2. `.call(AudioTranscriptionPrompt prompt)` → accepts a more detailed **prompt object**, which supports additional **options**

Since we want to customize things (like getting timestamps), we need to use the **second version**, with an `AudioTranscriptionPrompt`.

## Step 2: Understanding `AudioTranscriptionPrompt`

This is similar in spirit to `ImagePrompt` (which we used earlier for image generation) — it bundles together **what you're sending** and **how you want it processed**.

`AudioTranscriptionPrompt` needs **two things**:

1. The **audio resource** (our uploaded file, converted using `.getResource()`)
2. An **options object** (`AudioTranscriptionOptions`), where we configure things like response format, language, etc.

## Step 3: Building the Options Object

We create our options using `OpenAiAudioTranscriptionOptions`, along with the **Builder pattern**:

```java
AudioTranscriptionOptions options = OpenAiAudioTranscriptionOptions.builder()
        .build();
```

This creates a basic options object with defaults, which we'll customize step by step.

## Step 4: Creating the Prompt

```java
AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(file.getResource(), options);
```

**Explanation:**

- `file.getResource()` → our audio file, converted to a `Resource` (same as before)
- `options` → our configuration object, controlling how the transcription should behave

## Step 5: Calling the Model with This Prompt

```java
AudioTranscriptionResponse response = audioModel.call(prompt);
String transcript = response.getResult().getOutput();
```

**Explanation:**

- `.call(prompt)` → this time returns an `AudioTranscriptionResponse` object (not a plain `String` directly, since we're using the more detailed prompt-based version)
- `.getResult().getOutput()` → extracts the actual transcribed text `String` from the response, following the same familiar pattern we've used with other models throughout this course

## First Test: Confirming the Setup Works (No Customization Yet)

Before customizing anything, it's a good idea to verify that this new approach (using `AudioTranscriptionPrompt`) still works correctly, even with just the default options.

**Result:** Using a small test audio file, the transcription still works correctly, confirming our updated code structure is solid before we start customizing.

## Step 6: Exploring Available Options

Now, let's look at what we can actually configure on `OpenAiAudioTranscriptionOptions.builder()`. Some of the available options include:

| Option | Purpose |
|---|---|
| **Model** | Which specific transcription model to use |
| **Language** | Translate/transcribe into a specific target language (example: Spanish, French) |
| **Response format** | Controls the format of the returned transcription (plain text, or formats with timestamps) |
| **Temperature** | Controls the randomness/creativity of the output (similar in concept to temperature settings used with chat models) |

## Step 7: Adding Timestamps Using Response Format

To get timestamps included in our transcription, we need to set the **response format** to a subtitle-friendly format.

### Understanding Subtitle Formats

Two common subtitle format standards are commonly used:

- **SRT** → an older, widely-supported subtitle format
- **VTT** (WebVTT) → a newer subtitle format

> Either format works for including timestamps — the choice mostly depends on what your target platform/use case requires.

### Setting the Response Format

```java
AudioTranscriptionOptions options = OpenAiAudioTranscriptionOptions.builder()
        .responseFormat(TranscriptResponseFormat.SRT)
        .build();
```

**Explanation:**

- `.responseFormat(TranscriptResponseFormat.SRT)` → tells the model to return the transcription in **SRT format**, which includes timestamps alongside the text

## Step 8: Testing with Timestamps Enabled

After restarting the application and sending the same test request:

**Result:** The transcription now includes **timestamps** alongside the text, in a format similar to standard subtitle files:

```
Example (illustrative SRT-style output):
[00:00:00 --> 00:00:03] Hello, my name is Naveen Reddy, I run a channel...
```

This is exactly what's needed for building proper subtitles for a video.

## Step 9: Trying the Language Option (Translation)

Let's also try the **language** option, to see how it behaves.

```java
AudioTranscriptionOptions options = OpenAiAudioTranscriptionOptions.builder()
        .language("es")  // Spanish
        .build();
```

**Explanation:**

- `.language(...)` → allows specifying a target language for the transcription output

### Testing It

After restarting the application with the language option enabled and sending the same test request:

**Result:** The transcription is returned in **Spanish** instead of the original English — for example, containing words like *"Hola"* and *"Gracias"*.

> This shows that the transcription model isn't limited to simply transcribing audio in its original language — it can also **translate** the spoken content into a different target language as part of the same process.

## Full Example Code

```java
@RestController
public class AudioGenController {

    private OpenAiAudioTranscriptionModel audioModel;

    public AudioGenController(OpenAiAudioTranscriptionModel audioModel) {
        this.audioModel = audioModel;
    }

    @PostMapping("/api/stt")
    public String speechToText(@RequestParam MultipartFile file) {

        AudioTranscriptionOptions options = OpenAiAudioTranscriptionOptions.builder()
                .responseFormat(TranscriptResponseFormat.SRT)
                // .language("es")  // optional: enable for translation into Spanish
                .build();

        AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(file.getResource(), options);

        AudioTranscriptionResponse response = audioModel.call(prompt);

        return response.getResult().getOutput();
    }
}
```

## Quick Summary

| Concept | Meaning |
|---|---|
| `AudioTranscriptionPrompt` | Combines the audio resource and transcription options into a single request object |
| `OpenAiAudioTranscriptionOptions.builder()` | Used to configure transcription behavior (model, language, response format, temperature, etc.) |
| `.responseFormat(TranscriptResponseFormat.SRT)` | Requests the transcription in SRT format, which includes timestamps |
| `.language("es")` | Requests the transcription output translated into a specific target language (example: Spanish) |
| SRT / VTT | Common subtitle format standards that include timestamped text |

## Practice Questions

**Q1: Why couldn't we simply use `audioModel.call(file.getResource())` to get timestamps in the output?**
A: Because that simpler `.call(...)` method only accepts the audio resource, with no way to specify additional options like response format. To customize behavior (like adding timestamps), we need to use the `.call(AudioTranscriptionPrompt)` version instead.

**Q2: What two things does `AudioTranscriptionPrompt` require to be constructed?**
A: The audio resource (the uploaded file, converted via `.getResource()`) and an `AudioTranscriptionOptions` object.

**Q3: Which option controls whether timestamps are included in the transcription output, and what value enables this?**
A: The `responseFormat` option, set to a subtitle-friendly format like `TranscriptResponseFormat.SRT` (or a similar format like VTT).

**Q4: What does the `language` option do when configuring transcription?**
A: It allows specifying a target language, so the model translates the spoken audio content into that language as part of the transcription process (example: translating English speech into Spanish text).

**Q5: After calling `audioModel.call(prompt)` with an `AudioTranscriptionPrompt`, how do you extract the final transcribed text from the response?**
A: By calling `.getResult().getOutput()` on the returned `AudioTranscriptionResponse` object.
