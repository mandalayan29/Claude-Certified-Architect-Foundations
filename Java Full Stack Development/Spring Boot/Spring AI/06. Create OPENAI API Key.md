# Creating an OpenAI API Key and Adding It to Your Project

## What We Need

In the last topic, our Spring Boot project failed to run because a required property was missing:

```
spring.ai.openai.api-key
```

To fix this, we now need to actually **create an API key** from OpenAI and add it to our project.

> **Note:** This process is specific to OpenAI. If you use a different provider (Anthropic, Ollama, etc.) in the future, you will need to create a key the same way, but from that provider's own website/console.

## Step 1: Go to the OpenAI Website

1. Open your browser and go to `openai.com`
2. Click on **Login**
3. After logging in, you will see multiple options — make sure you select the **API platform**, **not ChatGPT**

> The API platform is meant for developers who want to use OpenAI inside their own applications. ChatGPT is just the chat website/app for normal users.

## Step 2: Add Billing Credits

Before creating a key, we need to make sure our account has some **credit/balance**, since OpenAI's API is a **paid service**.

Steps:

1. Click on **Settings**
2. Go to **Billing**
3. Add some credit (even a small/minimum amount is enough for learning and practice)

### Important Safety Tip

> **Do NOT enable "Auto Recharge"** while adding credits.

If auto-recharge is turned on, OpenAI will automatically keep adding money and charging you whenever your balance runs low. Keeping it **off** protects you from unexpected charges.

### Why Is It a Paid Service?

When you send a prompt to OpenAI, it runs on their large servers to generate a response. Since this requires real computing power, OpenAI charges for it.

- Charges are based on **tokens**
- A **token** is roughly a small piece of text (like a part of a word)
- The more tokens you **send** (your prompt) and **receive** (the AI's response), the more you get charged

```
Your Prompt (tokens) + AI Response (tokens) = Total tokens used --> Billing
```

> The cost per request is expected to reduce over time as these services become more efficient.

## Step 3: Create the API Key

Once your account has some credit, you can create your key:

1. Go to **API Keys** section
2. Click on **Create new secret key**
3. Give the key a name (example: `SpringAI-Demo`) — this is just for your own reference
4. Choose a **Project** (you can use the **default project**)
5. Choose the **permissions** for the key (for simplicity, you can allow all permissions)
6. Click **Create secure key**

### Very Important: Save Your Key Immediately

Once the key is created, OpenAI shows it to you **only once**.

- **Copy the key immediately** and save it somewhere safe (example: a notes file)
- You will **not** be able to view the full key again later
- **Never share your API key with anyone else** — anyone with your key can use your account and your credits

## Step 4: Add the Key to Your Spring Boot Project

Now go back to your Spring Boot project and open the `application.properties` file.

**Syntax:**

```
spring.ai.openai.api-key=<YOUR_ACTUAL_API_KEY>
```

**Example:**

```
spring.ai.openai.api-key=sk-your-real-api-key-here
```

> Replace the placeholder with your **own real key** copied from OpenAI. Keep this key private — do not commit it to public code repositories (like public GitHub repos).

## Step 5: Run the Project Again

Now, let's run the project again.

### Result

This time, the application **starts successfully**, without any error:

```
Started Application on port 8080
```

### But Wait — AI Features Still Don't Work Yet

Even though the application starts fine now, we **still cannot use any AI features**.

**Why?** Because so far, we have only:

1. Created the project
2. Added dependencies (Spring Web, OpenAI)
3. Added the API key

We have **not yet written any actual code** that uses Spring AI to send a prompt or get a response. Adding that code is the next step, covered separately.

> **Fun fact:** Even an **invalid/fake key** would let the application start successfully — the check at startup is only about whether the property exists, not whether the key is actually valid. However, to actually get real responses from OpenAI, you need a valid, working key.

## Quick Summary

| Step | Action |
|---|---|
| 1 | Go to `openai.com` → Login → select **API platform** (not ChatGPT) |
| 2 | Go to **Settings → Billing** → add credit (keep Auto Recharge **off**) |
| 3 | Go to **API Keys** → Create new secret key → name it → set permissions → create |
| 4 | **Copy and save the key immediately** (shown only once) |
| 5 | Paste the key into `application.properties` as `spring.ai.openai.api-key` |
| 6 | Run the project → it starts successfully with no error |

## Practice Questions

**Q1: Where should you go on the OpenAI website to create an API key — ChatGPT or API platform?**
A: The API platform, not ChatGPT.

**Q2: Why do you need to add billing credit before creating and using an API key?**
A: Because OpenAI's API is a paid service — it charges based on the number of tokens used in your prompt and the AI's response.

**Q3: Why is it recommended to keep "Auto Recharge" turned off?**
A: To avoid OpenAI automatically adding money and charging you repeatedly without your direct control, protecting you from unexpected charges.

**Q4: What must you do immediately after creating a new API key, and why?**
A: You must copy and save the key right away, because OpenAI shows the full key only once — you cannot view it again later.

**Q5: After adding a valid API key and successfully running the project, can you already use AI features like sending a prompt?**
A: No. The application starts without error, but no AI features work yet because no actual Spring AI code has been written to send prompts or get responses.
