# Implementing Prompt Templates: Movie Recommendation Example

## Step 1: Plan the API Request

Before writing any code, let's first plan what our request should look like.

We want to create a new endpoint that recommends a movie, based on three inputs:

- **Type** of movie (example: `comedy`)
- **Year/decade** (example: `2010`)
- **Language** (example: `English`)

### Planned Request

```
POST http://localhost:8080/api/recommend?type=comedy&year=2010&lang=English
```

- **Method:** `POST`
- **Parameters:** `type`, `year`, `lang` (sent as request parameters/query parameters)

At this point, since we haven't written the controller method yet, sending this request will fail (no matching endpoint exists).

## Step 2: Create the Controller Method

Let's add a new method inside our existing controller (in a real project, you may prefer a separate file, but here we keep it simple in the same class).

### Basic Method Structure

```java
@PostMapping("/api/recommend")
public String recommend(
        @RequestParam String type,
        @RequestParam String year,
        @RequestParam String lang) {

    // logic goes here
}
```

**Explanation:**

- `@PostMapping("/api/recommend")` → maps this method to handle `POST` requests at `/api/recommend`
- `@RequestParam String type` → captures the `type` value from the request
- `@RequestParam String year` → captures the `year` value from the request
- `@RequestParam String lang` → captures the `lang` value from the request

> **Tip:** It's better to name your request parameter `lang` (instead of something like `language`) to keep the URL short and simple — just make sure your API client (Insomnia, Postman, etc.) sends the parameter with the same name.

## Step 3: Sending a Basic Response (Without a Template Yet)

Just like before, we can send a request using `ChatClient`:

```java
String response = chatClient
        .prompt()
        .call()
        .content();

return response;
```

This is the same pattern we used earlier. But right now, there's a problem: **we haven't actually built any prompt using the `type`, `year`, and `lang` values yet.**

We *could* simply build a plain string manually and pass it to `.prompt(...)`. But instead, we want to use something more structured and reusable: a **Prompt Template**.

## Step 4: What Is a Prompt Template?

A **Prompt Template** lets you define a prompt with **placeholders** — parts of the text that can be replaced later with actual values.

```
Prompt Template (with placeholders):
"I want to watch {type} movie ... around {year} ... in {lang}."

        |
        v
Fill in actual values: type=comedy, year=2010, lang=English

        |
        v
Final Prompt:
"I want to watch comedy movie ... around 2010 ... in English."
```

This is useful when:

- You want to **reuse** the same prompt structure with different values
- You want to build the prompt from **specific values**, instead of asking the user to type a full sentence

## Step 5: Creating a PromptTemplate Object

To use a prompt template in Spring AI, we use the `PromptTemplate` class.

**Syntax:**

```java
PromptTemplate promptTemplate = new PromptTemplate(<template_string>);
```

**Example (starting point, still empty):**

```java
PromptTemplate promptTemplate = new PromptTemplate("");
```

We will fill in the actual template text shortly.

## Step 6: Writing the Prompt Text (Using Text Blocks)

Since our prompt will span multiple lines, we use Java's **text block** feature (a newer Java syntax that allows multi-line strings without manually adding `\n` for new lines).

**Syntax (text block):**

```java
String text = """
    line 1
    line 2
    """;
```

### Our Movie Recommendation Prompt

```java
PromptTemplate promptTemplate = new PromptTemplate("""
        I want to watch {type} movie tonight with good rating.
        Looking for a movie around this year {year}.
        The language I am looking for is {lang}.
        Suggest specific movie, don't confuse me.
        Also tell me the cast of the movie.
        Also mention the length of the movie.
        """);
```

**Explanation:**

- `{type}`, `{year}`, `{lang}` → placeholders that will be replaced with real values later
- The rest of the text guides the AI to behave the way we want:
  - **"Suggest specific movie, don't confuse me"** → ensures the AI gives **one clear recommendation**, not a long list
  - **"Also tell me the cast"** and **"mention the length"** → asks for extra, useful details along with the recommendation

> This is a great example of how prompt engineering works — the more clearly and specifically you describe what you want, the better and more predictable the AI's response will be.

## Step 7: Creating the Prompt Object from the Template

Having a `PromptTemplate` alone is not enough — we need to convert it into an actual `Prompt` object before sending it through `ChatClient`.

**Syntax:**

```java
Prompt prompt = promptTemplate.create();
```

This creates a `Prompt` object from our template. We can now pass this `prompt` object into `.prompt(...)`:

```java
String response = chatClient
        .prompt(prompt)
        .call()
        .content();
```

## Step 8: The Missing Step — Filling in the Placeholder Values

At this point, if you test the code, you will get an error like:

```
Missing variable: type, year, lang
```

This happens because **we defined placeholders, but never told Spring AI what values to use for them.**

### Fixing It: Passing a Map of Values

The `.create()` method also accepts a **`Map`** of values, used to fill in the placeholders.

**Syntax:**

```java
Prompt prompt = promptTemplate.create(
    Map.of("type", type, "year", year, "lang", lang)
);
```

**Explanation:**

- `Map.of(...)` → creates a simple key-value map
- Each key (example: `"type"`) matches a placeholder name (`{type}`) in our template
- Each value (example: `type`) is the actual variable received from the request parameters

Now, when the prompt is generated:

- `{type}` gets replaced with the actual `type` value (example: `comedy`)
- `{year}` gets replaced with the actual `year` value (example: `2010`)
- `{lang}` gets replaced with the actual `lang` value (example: `English`)

## Full Example Code

```java
@PostMapping("/api/recommend")
public String recommend(
        @RequestParam String type,
        @RequestParam String year,
        @RequestParam String lang) {

    PromptTemplate promptTemplate = new PromptTemplate("""
            I want to watch {type} movie tonight with good rating.
            Looking for a movie around this year {year}.
            The language I am looking for is {lang}.
            Suggest specific movie, don't confuse me.
            Also tell me the cast of the movie.
            Also mention the length of the movie.
            """);

    Prompt prompt = promptTemplate.create(
        Map.of("type", type, "year", year, "lang", lang)
    );

    String response = chatClient
            .prompt(prompt)
            .call()
            .content();

    return response;
}
```

## Step 9: Testing It

1. Restart the application
2. Send a `POST` request:

```
POST http://localhost:8080/api/recommend?type=comedy&year=2010&lang=English
```

**Result:** The AI responds with a specific movie recommendation, including the cast and the movie's length — exactly what we asked for in our prompt.

### Trying Different Values

You can now easily test different combinations, without changing any code — just change the request parameters:

- `type=comedy`, `lang=Hindi` → get a Hindi comedy movie recommendation
- `type=horror`, `lang=Telugu` → get a Telugu horror movie recommendation

Each time, the **same reusable template** is used — only the actual values change.

## Step 10: Refining the Prompt for a Better Response Format

The AI's response format may not always match exactly what you want (example: the order of details like plot, cast, length, rating may vary). You can fix this by being **even more specific** in your prompt template.

### Improved Prompt (Example)

```java
PromptTemplate promptTemplate = new PromptTemplate("""
        I want to watch {type} movie tonight with good rating.
        Looking for a movie around this year {year}.
        The language I am looking for is {lang}.
        Suggest specific movie, don't confuse me.
        The movie should be under 110 minutes and should have a good rating.

        Respond in this exact format:
        Movie Name:
        Basic Plot:
        Cast:
        Length:
        IMDB Rating:
        """);
```

**What changed:**

- Added a specific constraint: movie length **under 110 minutes**, with a good rating
- Added an explicit **response format**, telling the AI exactly what fields to include and in what order

### Result

After this change, the AI's response follows the **exact structure** we asked for — Movie Name, Basic Plot, Cast, Length, and IMDB Rating, in that specific order.

> This shows an important lesson in **prompt engineering**: the more precisely you describe both the **content** you want and the **format** you want it in, the more consistent and useful the AI's responses become.

## Quick Summary

| Concept | Meaning |
|---|---|
| `PromptTemplate` | A class used to define a reusable prompt with placeholders (example: `{type}`) |
| Placeholder (`{name}`) | A part of the template that gets replaced later with an actual value |
| `promptTemplate.create(Map.of(...))` | Creates a final `Prompt` object, filling in the placeholders using a map of values |
| Text block (`"""`) | A Java syntax feature for writing multi-line strings easily |
| `@RequestParam` | Captures a value sent as a request parameter (used here for `type`, `year`, `lang`) |
| Prompt engineering | Carefully wording your prompt (including format instructions) to get better, more predictable AI responses |

## Practice Questions

**Q1: What is a Prompt Template, and why is it useful?**
A: A Prompt Template is a reusable prompt structure with placeholders that can be filled in with different values. It is useful when you want to build a consistent, reusable prompt from specific values, rather than relying on a free-form user-typed prompt.

**Q2: What error occurs if you define placeholders in a `PromptTemplate` but never fill them in, and why?**
A: An error like "Missing variable: type, year, lang" occurs, because the template still contains unresolved placeholders that were never replaced with actual values.

**Q3: How do you fill in the placeholder values when creating a `Prompt` from a `PromptTemplate`?**
A: By passing a `Map` of values to the `.create()` method, where each key matches a placeholder name in the template (example: `promptTemplate.create(Map.of("type", type, "year", year, "lang", lang))`).

**Q4: What Java feature is used to write a clean, multi-line prompt string, and what is its benefit?**
A: Java's text block feature (using `"""`). It allows writing multi-line strings naturally, without needing to manually add newline characters (`\n`).

**Q5: How can you make the AI's response follow a specific, consistent format (example: Movie Name, Plot, Cast, Length, Rating in that order)?**
A: By explicitly specifying the desired response format inside the prompt template itself, clearly listing the fields and their order.
