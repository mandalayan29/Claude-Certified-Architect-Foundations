# Analyzing Images with AI (Image-to-Text): Planning the Request

## Moving in the Opposite Direction

So far, we've generated images **from text** (text-to-image). Now, let's flip this around: giving an **image** to an AI model, and asking it to **describe, analyze, or answer questions about** that image (image-to-text).

### Real-World Example

Imagine taking a photo of an object you don't recognize — maybe a collectible figure, a gadget, or a product — and asking the AI: *"What is this?"* The AI can look at the image and give you a meaningful answer, based on what it visually recognizes.

## Step 1: Planning the Request Using an API Client

Before writing any backend code, let's first plan out **how we'll send an image** to our application using Insomnia (or a similar API client).

### Basic Setup

- **URL:** `http://localhost:8080/image/describe`
- **Method:** `POST`

### Sending the Text Query

Just like before, we can send a **query parameter** — but this time, it's not just a generic "describe" instruction. It can also be a **specific question** about the image.

**Example queries:**

- `"describe"` → a general description of the image
- `"tell me the name of the superhero"` → a specific question about the image's content

> This flexibility is useful — depending on your use case, you might want a general description, or a very specific, targeted question about what's in the image.

### Sending the Actual Image File

Since we need to send an actual **image file** (not just text), we can't use a simple query parameter for this. Instead, we use a different request format:

1. Go to the **Body** section of your request
2. Select **Form Data** as the body type
3. Add a new field, and set its type to **File** (instead of plain text)
4. Name this field (example: `file`, or `image` — any name works, as long as it matches what our backend code expects)
5. Choose the actual image file from your computer to upload

```
Request Body (Form Data):
   |
   |--- file  --> [Selected image file, e.g., a photo of a Deadpool figure]
```

### Example Test (Before Backend Code Exists)

- **Query:** `"tell me the name of the superhero"`
- **File:** a photo of a Deadpool figure

At this point, clicking **Send** will fail, since:

- Our server might not even be running yet, or
- Even if it is running, we **haven't created a method yet** to handle this specific type of request (accepting both an image file and a text query together)

## Step 2: Understanding What Our Backend Needs to Accept

To handle this kind of request, our controller method will need to accept **two separate pieces of information**:

1. **The text query** (example: "tell me the name of the superhero") — a simple `String`
2. **The image file itself** — this needs to be handled as a **`MultipartFile`**

> **What is a `MultipartFile`?** When you upload an actual file (like an image) through a web request, it's typically sent as part of a special request format called **multipart** data — this is different from sending plain text parameters. Spring provides a built-in type called `MultipartFile` specifically to handle this kind of file upload cleanly in your controller methods.

## Step 3: The Overall Plan for Our Controller Method

```
1. Accept the text query (String) from the request
2. Accept the uploaded image (MultipartFile) from the request
3. Combine both the image and the query into a request the AI model understands
4. Send this combined request to the AI model
5. Return the AI's response (its description/analysis of the image)
```

## Quick Summary

| Concept | Meaning |
|---|---|
| Image-to-Text | Giving an AI model an image and asking it to describe, analyze, or answer questions about it |
| Form Data (in API client) | The request body format used when sending files (like images) alongside other fields |
| `MultipartFile` | Spring's built-in type used to handle file uploads (like images) in a controller method |
| Combining query + image | Our controller will need to accept both a text query and an image file together, to send a complete request to the AI model |

## Practice Questions

**Q1: What is the key difference between the image generation we did earlier and what we're planning now?**
A: Earlier, we generated an image from a text description (text-to-image). Now, we're planning to give an image to the AI and get a text description/analysis back (image-to-text).

**Q2: Why can't an image file be sent as a simple query parameter in an API request?**
A: Because an image is actual file data, not plain text, so it needs to be sent using a different request format — typically as multipart form data, with the file attached as its own field.

**Q3: What Spring type is typically used in a controller method to accept an uploaded file (like an image)?**
A: `MultipartFile`

**Q4: What two pieces of information does our planned controller method need to accept together?**
A: A text query (as a `String`) and the uploaded image (as a `MultipartFile`).

**Q5: Give an example of a specific (not just general) question you might ask about an uploaded image.**
A: Any reasonable example, such as: "Tell me the name of the superhero in this image," instead of a generic "describe this image" request.
