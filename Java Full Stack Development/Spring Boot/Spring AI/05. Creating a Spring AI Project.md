# Creating a Spring Boot Project with Spring AI

## Goal

In this tutorial, we will create a **Spring Boot project** that includes the **Spring AI** module. We will use **Spring Initializr** to generate this project.

## Tool Used: Spring Initializr

**Spring Initializr** is a web tool used to quickly create a ready-to-use Spring Boot project with the dependencies you need.

- Website: `start.spring.io`

> **Note:** If you have the **Ultimate version** of IntelliJ (or Eclipse), you can also create a Spring Boot project directly from inside the IDE. In this tutorial, we are using the **Community version**, so we will use the Spring Initializr website instead.

## Project Settings

While creating the project on Spring Initializr, we set the following options:

| Setting | Value |
|---|---|
| Project Type | Maven |
| Language | Java |
| Spring Boot Version | (latest stable version shown) |
| Group ID | `com.telescope` |
| Artifact / Project Name | `springcode` |

We do not need to change most other default settings.

## Adding Dependencies

This is the most important part — choosing the right **dependencies**.

### Step 1: Add Spring Web

Since we are building a **web application**, we add the **Spring Web** dependency.

### Step 2: Add Spring AI (Model-Specific)

As we learned earlier, Spring AI supports different LLM providers, and **each provider needs its own dependency**. To add a dependency:

1. Click on **Add Dependency**
2. Search for the provider you want to use
3. Select the correct one from the list

Here are some examples:

| If you want to use... | Search for... |
|---|---|
| OpenAI | `OpenAI` → select **OpenAI** (not "Azure OpenAI") |
| Anthropic (Claude) | `Anthropic` |
| Ollama (local models) | `Llama` |
| Google Vertex AI | `Vertex` |

> **Important:** Be careful while selecting OpenAI. There are two similar-looking options — **OpenAI** and **Azure OpenAI**. Make sure you pick the correct one based on what you actually want to use.

For this tutorial, we are using **OpenAI**, so we add:

1. **Spring Web**
2. **OpenAI**

### What Gets Added Behind the Scenes

Once you add these two dependencies, Spring Initializr shows you exactly what will be included in the project. You can click **Explore** to check this before downloading. It includes:

- `spring-boot-starter-web`
- `spring-ai-openai-spring-boot-starter`

## Generating and Opening the Project

1. Click **Generate** on Spring Initializr
2. This downloads the project as a `.zip` file
3. Extract it and open it in your IDE (example: IntelliJ)

## Checking the Project Files

### 1. The `pom.xml` File

When you open the `pom.xml` file, you will see the two dependencies we added:

```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-openai-spring-boot-starter</artifactId>
</dependency>

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```

- `spring-ai-openai-spring-boot-starter` → adds Spring AI support for OpenAI
- `spring-boot-starter-web` → adds support for building web applications (runs on **Tomcat** by default)

### 2. The Main Code

Since this is a brand-new, simple project, there is **very little code** in the main application class at this point. We have not written any custom logic yet.

### 3. `application.properties` File

Inside the `resources` folder, you will find the `application.properties` file. At this point, it has only **one line** in it (the default application name property).

## Running the Project (First Attempt)

Let's try running this project as it is, even though we haven't written any custom code yet.

Steps:

1. Right-click on the project
2. Select **Run**

### Result: It Fails

Even though we have written no code of our own, the application **fails to start**. This might seem confusing at first, but there is a clear reason.

### Understanding the Error

If you scroll through the error logs, you will see a message like this:

```
OpenAI API key must be set
```

This tells us that a required property is missing:

```
spring.ai.openai.api-key
```

Spring Boot needs this property to know **which API key to use** while connecting to OpenAI. Since we haven't provided it yet, the application cannot start.

## Adding the Property (Placeholder)

To fix this, we need to go to the `application.properties` file and add this property:

**Syntax:**

```
spring.ai.openai.api-key=<YOUR_API_KEY_HERE>
```

**Example (placeholder):**

```
spring.ai.openai.api-key=your-api-key-goes-here
```

At this point, we don't have the actual API key yet — we only know **where** it needs to be added.

> **Where do we get this API key from?** That is explained separately, since it involves creating an account with OpenAI and generating a key from their developer console.

## Practice Questions

**Q1: Which two dependencies were added while creating this Spring Boot project?**
A: Spring Web and OpenAI (Spring AI OpenAI starter).

**Q2: What is the difference between selecting "OpenAI" and "Azure OpenAI" while adding dependencies?**
A: They are two different, similar-looking options. You must select the correct one based on which service you actually plan to use — in this case, plain OpenAI, not Azure OpenAI.

**Q3: Why did the project fail to run, even though no custom code was written?**
A: Because the required property `spring.ai.openai.api-key` was missing. Spring AI needs this API key to connect to OpenAI, and without it, the application fails to start.

**Q4: What is the correct property name used to set the OpenAI API key in `application.properties`?**
A: `spring.ai.openai.api-key`

**Q5: What does the `spring-ai-openai-spring-boot-starter` dependency provide?**
A: It adds Spring AI's support for connecting to and working with OpenAI models.
