# Introduction to Spring AI

## Why Do We Need AI in Enterprise Applications?

When we build enterprise applications, we normally use Spring Boot. Spring Boot has many modules that help us build strong applications:

- **Spring Web** – to build web applications and REST APIs
- **Spring JPA** – to work with databases easily
- **Spring Security** – to secure our application

These modules are enough to build a normal enterprise application. But today, we are living in the world of AI. AI is used almost everywhere:

- Writing an essay → we ask AI
- Writing an email → we ask AI
- Answering questions → we ask AI (ChatGPT, Gemini, etc.)

We type a prompt (our question), and the AI tool gives us a response. Sometimes we copy that response directly and use it (with small changes).

Since AI is so useful, businesses also want to add AI features inside their own applications — not just use AI tools separately.

## Where Do We Use AI in a Real Application?

Let's say you are building an **e-commerce website**. Here are some places where AI can help:

1. **Chatbot** – To answer customer questions automatically
2. **Product description generator** – To auto-generate a description when a new product is added
3. **Image generator** – To auto-generate a product image using AI

So the question is: **how do we add these AI features inside our Java/Spring application?**

## The Problem: Mixing Java and Python

Most AI tools and libraries are very popular in the **Python** world. So a common approach is:

- Build the main application in **Java (Spring Boot)**
- Build the AI part separately in **Python**
- Connect both using API calls

This creates a problem:

```
Java Application  <---- API Calls ---->  Python AI Service
     (Team A)                                (Team B)
```

- You need **two different teams** (one for Java, one for Python)
- There is a lot of **API calling** happening between the two systems
- This adds extra complexity to maintain and manage

### A Better Solution

What if we could talk to AI models **directly from Java**, without needing a separate Python service? This would remove the need for cross-language API calls and separate teams.

This is exactly the gap that **Spring AI** fills.

## Understanding LLM Models

Before going further, let's understand a few basic terms.

**LLM** stands for **Large Language Model**. These are AI models trained to understand and generate human-like text.

Some well-known LLM service providers are:

| Provider | Model / Product |
|---|---|
| OpenAI | ChatGPT |
| Anthropic | Claude |
| Google | Gemini |
| Ollama | Run models locally on your own machine |

These LLM models are **proprietary** — meaning the companies own them and run them on their own servers. Normally, we access them through a chat interface (like ChatGPT or Gemini's website).

### Using LLMs as a Service

If we want to use these models **inside our own application**, these companies also offer their models as a **service** (sometimes called **MaaS – Model as a Service**). The general steps are:

1. Create an account with the provider (OpenAI, Anthropic, etc.)
2. Add some credit/balance to your account
3. Get an **API key**
4. Send requests to the model using that key
5. Receive a response back

We will go through these steps in detail later in this course.

## What is Spring AI?

To connect our Enterprise Java application with LLM models, we need a middle layer. That layer is **Spring AI**.

> **Spring AI** is an application framework for AI engineering. It lets you add Generative AI (Gen AI) features into your Spring applications easily.

In simple words: Spring AI sits **between your application and the LLM models**, and makes it easy for both sides to talk to each other.

```
+------------------------+       +--------------+       +----------------+
|  Your Spring Boot App  | <---> |  Spring AI   | <----> |  LLM Models    |
|  (Business Logic)      |       |  (Middle     |       |  (OpenAI,      |
|                        |       |   Layer)     |       |   Claude, etc.)|
+------------------------+       +--------------+       +----------------+
```

Spring AI is available as one of the official Spring projects, alongside Spring Web, Spring JPA, Spring Security, and others.

## What Can Spring AI Do?

Spring AI supports many different **model types**. This means it is not limited to just chatting with text — it supports multiple AI capabilities:

- **Chat Completion** – Sending a prompt and getting a text response (like a chatbot)
- **Embedding** – Converting text into a numeric format (used for search and comparison)
- **Text to Image** – Generating an image from a text description
- **Audio Transcription** – Converting speech/audio into text
- **Text to Speech** – Converting text into spoken audio
- **Moderation** – Checking content for safety/appropriateness

We will try to cover as many of these features as possible in this course.

A: Because most AI tools are Python-based, so you need a separate Python service, extra API calls between Java and Python, and two different teams to maintain them.

**Q2: What does LLM stand for?**
A: Large Language Model.

**Q3: What is Spring AI?**
A: It is a Spring framework project that acts as a middle layer between your Java application and LLM models, making it easy to add Generative AI features directly in Java.
