# A Note on Spring AI Versions (Snapshot vs Stable)

## Why This Note Is Important

Before creating our first Spring AI project, it is important to understand something about **versions**.

When the videos for this course were originally recorded, Spring AI did not have a final stable release yet. At that time, the course used either a:

- **SNAPSHOT version**, or
- **Milestone version**

These are early, in-development versions of the framework.

## What Changed

Since then, Spring AI has released its first **stable version**:

```
Spring AI stable version: 1.0.0
```

Along with this stable release, a few small things have changed:

- Some **package names** and **artifact names** were updated (to make things more standard/consistent)
- A few small **syntax changes** in the code

> **Important:** The core **concepts stay exactly the same**. Only some naming and syntax details are slightly different.

## How to Handle This While Watching the Course

Since re-recording every video would take a lot of extra time, here is how the course handles this version change:

1. In some videos, wherever the code or version has changed, you will see an **overlay** showing the **new/updated code**
2. When you see this overlay, always use the **new code shown in the overlay**, not the older code visible in the original screen recording
3. This overlay will **not appear in every video** — only in the videos where something actually changed

```
While Watching:
   |
   |--- No overlay shown --> Use the code as shown in the recording
   |
   |--- Overlay shown --> Use the NEW code from the overlay
                           (ignore the old code in the recording)
```

## Example: Spring Initializr Changes

One place where this version change is visible is in the **Spring Initializr** (the tool used to create a new Spring Boot project). For example:

- When selecting **Maven** as the build tool
- Choosing the **Spring Boot version** → now shows a stable version like `3.3.5`
- Adding dependencies (example: selecting **OpenAI** as a dependency)

Earlier, this dependency would show a snapshot/milestone version. Now, if you click on **Explore** in Spring Initializr, you will see it uses the stable version:

```
Spring AI version: 1.0.0
```

The **artifact name** (project/package identifier) for some dependencies has also been standardized and may look slightly different from what is shown in the recording.

## Where to Get the Latest Working Code

If you are ever unsure about the correct code to use, there are two reliable options:

1. **Watch for the overlay** in the video (new code shown on screen)
2. **Check the GitHub repository** provided with this course — it always contains the **latest, working code**

## Key Takeaway

| Point | Detail |
|---|---|
| Old version used in recordings | SNAPSHOT / Milestone version |
| Current stable version | Spring AI `1.0.0` |
| What changed | Some package/artifact names, some syntax |
| What stayed the same | All core concepts |
| How to get correct code | Follow on-screen overlays, or use the GitHub repository |

> Don't worry about version differences. Keep following the course — the **concepts you learn remain valid**, even if small syntax details are slightly different in the newer version.
