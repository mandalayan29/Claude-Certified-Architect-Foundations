# Working with ChatResponse and Metadata

## Recap: What We Had Before

In the previous topic, we used `.content()` at the end of our `ChatClient` chain to directly get a plain text `String` response:

```java
String response = chatClient
        .prompt(message)
        .call()
        .content();
```

This is simple and works well when you only care about the **text answer**. But sometimes, you want **more than just the text** — for example, extra details about the response.

## Introducing `chatResponse()`

Instead of calling `.content()`, we can call `.chatResponse()`.

```
chatClient.prompt(message).call().chatResponse()
```

- `.content()` → gives you a plain `String`
- `.chatResponse()` → gives you a full **`ChatResponse` object**, which contains much more information than just the text

> A `ChatResponse` represents the **full chat completion response** returned by the AI provider — not just the answer text, but extra details around it too.

## What Can You Get From `ChatResponse`?

The `ChatResponse` object has multiple useful methods. Some important ones:

| Method | What It Gives You |
|---|---|
| `getResult()` | The main result (a `Generation` object) — used to get the actual text |
| `getResults()` | Multiple results (useful when the model returns more than one output) |
| `getMetadata()` | Extra information — like which model was used, usage details, rate limits, etc. |

## Getting the Text from ChatResponse

Since `ChatResponse` is not a plain `String`, we cannot return it directly. To get the actual text answer, we need to go a few steps deeper:

```
chatResponse
   |
   |--- getResult()      --> returns a "Generation" object
           |
           |--- getOutput()   --> returns the output details
                    |
                    |--- getText()  --> finally gives you the plain text (String)
```

### Code Example

```java
@GetMapping("/api/{message}")
public ResponseEntity<String> getAnswer(@PathVariable String message) {

    ChatResponse chatResponse = chatClient
            .prompt(message)
            .call()
            .chatResponse();

    String response = chatResponse
            .getResult()
            .getOutput()
            .getText();

    return ResponseEntity.ok(response);
}
```

**Explanation:**

- `.chatResponse()` → sends the request and gets back the full `ChatResponse` object (instead of just plain text)
- `.getResult()` → gets the main `Generation` result from the response
- `.getOutput()` → gets the output details from that result
- `.getText()` → finally extracts the plain text answer as a `String`

> **Note:** There are other useful methods too, like `getFirst()` and `getLast()`, which help when a response contains multiple outputs. These are useful in more advanced scenarios (example: asking for multiple responses at once), and are covered later.

## Reading the Metadata

Now let's also read some extra information using `getMetadata()`.

```java
System.out.println(chatResponse.getMetadata().getModel());
```

**Explanation:**

- `chatResponse.getMetadata()` → returns a `ChatResponseMetadata` object, which contains extra details about the response
- `.getModel()` → returns a `String` — the exact AI model that generated this response (example: `gpt-4o-mini`)

Apart from the model name, the metadata object can also give you other useful details, such as:

- **Prompt metadata** – information about the prompt that was sent
- **Rate limit information** – how many requests you can still make
- **Usage information** – how many tokens were used for this request

For now, we are only printing the **model name** to the console (not sending it back to the user), just to confirm it is working.

## Updated Full Code

```java
@RestController
public class OpenAIController {

    private final ChatClient chatClient;

    public OpenAIController(ChatModel chatModel) {
        this.chatClient = ChatClient.create(chatModel);
    }

    @GetMapping("/api/{message}")
    public ResponseEntity<String> getAnswer(@PathVariable String message) {

        ChatResponse chatResponse = chatClient
                .prompt(message)
                .call()
                .chatResponse();

        String response = chatResponse
                .getResult()
                .getOutput()
                .getText();

        System.out.println(chatResponse.getMetadata().getModel());

        return ResponseEntity.ok(response);
    }
}
```

## A Word of Caution: NullPointerException Warning

While writing this code, your IDE may show a warning like:

```
Method invocation 'getMetadata()' may produce 'NullPointerException'
```

This is a normal warning from the IDE, reminding you that `chatResponse` (or its inner objects) could technically be `null` in some situations. In a real production application, you should **check for null values** before accessing them, and handle the case properly (example: return a message like *"I have not received any input or output from the AI model"* if `chatResponse` is `null`).

> Since this is a learning-focused example, we are keeping the code simple and skipping the null checks for now. In real projects, always add proper null checks and error handling.

## Quick Summary

| Concept | Meaning |
|---|---|
| `.chatResponse()` | Returns the full `ChatResponse` object instead of plain text |
| `getResult()` | Gets the main `Generation` result from the response |
| `getOutput().getText()` | Extracts the plain text answer from the result |
| `getMetadata()` | Returns extra details about the response (model, usage, rate limits, etc.) |
| `getMetadata().getModel()` | Returns the exact AI model name used to generate the response |
| `getResults()` | Used when a response contains multiple outputs (advanced use case) |

## Practice Questions

**Q1: What is the main difference between calling `.content()` and `.chatResponse()`?**
A: `.content()` directly returns a plain `String` with just the answer text. `.chatResponse()` returns a full `ChatResponse` object, which includes the text plus extra details like metadata.

**Q2: What is the correct chain of method calls to get the plain text answer from a `ChatResponse` object?**
A: `chatResponse.getResult().getOutput().getText()`

**Q3: What does `getMetadata()` return, and what kind of information can it give you?**
A: It returns a `ChatResponseMetadata` object, which can give details like the model used, prompt metadata, rate limit information, and token usage.

**Q4: How do you find out which exact AI model generated a given response?**
A: By calling `chatResponse.getMetadata().getModel()`, which returns the model name as a `String`.

**Q5: Why does the IDE show a "may produce NullPointerException" warning when calling `getMetadata()`?**
A: Because `chatResponse` or its inner objects could technically be `null` in some situations, and the IDE is warning that a proper null check should ideally be done before accessing them.
